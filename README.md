## Overview

Nested Android MusicSoftware project snapshot with Gradle build files and application source.

## Open the Android project

1. Clone or download this repository.
2. In Android Studio, open `MusicSoftware-master/MusicSoftware-master/`, which contains the Gradle settings and application module.
3. Review the committed Gradle plugin, SDK, and dependency versions before syncing. These are historical project snapshots and may need a compatible toolchain.
4. Configure any external services required by the application source, then build and run on a suitable emulator or device.
